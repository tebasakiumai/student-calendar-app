# 就活カレンダー / Student Calendar App

大学生・就活生向けのデスクトップカレンダーアプリです。就活・学校・趣味など、自分で自由に作成できる「レイヤー」で予定を管理し、1週間以内の締め切りをひと目で確認できます。

## 主な機能

- **レイヤー管理**：就活・学校・趣味など、レイヤーを自由に追加・名前変更・色変更・削除できる（Edgeのタブグループのようなイメージ）
- **予定のCRUD**：タイトル・メモ・期限・終日/時間指定・提出先リンク・ステータス（未着手/進行中/完了）を持つ予定を追加・編集・削除
- **今週の締め切り一覧**：期限が近い順に、あと何日かをカウントダウン表示
- **月間カレンダー**：Googleカレンダー風のマス目表示。日付のクリックでその日のタイムライン、ダブルクリックで予定追加、予定のクリックで詳細パネルを表示
- **日別タイムライン**：8〜24時のスケジュールを横スクロールで確認（ドラッグ・トラックパッドの2本指スワイプ対応）
- **データの永続化**：`electron-store`を使い、PCのローカルにデータを自動保存。アプリを閉じても消えない
- **手帳・ノート風デザイン**：紙のような配色とインクカラーを基調にしたオリジナルテーマ

## 使用技術と選定理由

| 技術 | 理由 |
|---|---|
| **TypeScript** | 2026年現在のWeb系企業の新卒採用でほぼ標準スキル化しているため。型があることで、開発中のバグも大幅に減らせた |
| **React** | コンポーネント単位での設計、状態管理（state/props）の基礎を実践的に学べるため |
| **Electron** | Webの技術（HTML/CSS/JS）でそのままデスクトップアプリ化できるため。 crossplatform対応も視野に入れやすい |
| **electron-store** | PC上へのデータ永続化をシンプルなAPIで実現。v8系を使用（v9以降はESM専用のため今回の構成とは非互換） |
| **date-fns** | 日付の計算（締め切りまでの日数、週内判定など）を安全かつ簡潔に扱うため |
| **electron-builder** | Windows向けの配布用インストーラー（.exe）をビルドするため |

## セットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発モードで起動
npm run dev
```

## ビルド（配布用インストーラーの作成）

```bash
npm run build:win
```

`dist`フォルダ内に `.exe` インストーラーが生成されます。

## プロジェクト構成

```
src/
├── main/           # メインプロセス（データ保存の窓口、electron-store）
├── preload/        # レンダラーとメインプロセスの橋渡し（IPC）
└── renderer/src/
    ├── App.tsx          # 状態管理・レイアウトの中心
    ├── CalendarGrid.tsx # 月間カレンダーの表示部品
    ├── DayView.tsx      # 日別タイムラインの表示部品
    ├── types.ts         # 型定義（Layer, CalendarEvent）
    └── App.css          # デザイン定義
```
